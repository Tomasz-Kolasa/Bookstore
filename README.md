# Bookstore

A simple **bookstore simulation written in C#**, developed as part of university laboratory exercises.

The project was created for educational purposes to practice C# programming, object-oriented programming and the implementation of basic business logic.

## Project Overview

The application simulates a simple bookstore and its basic operations.

The project focuses on implementing a small domain model representing a bookstore rather than building a production-ready e-commerce application.

## Technologies

* **C#**
* **.NET**
* **Object-oriented programming**

## Features

The application provides basic bookstore functionality, including:

* managing books
* working with bookstore data
* performing basic bookstore operations
* implementing application logic using C# classes and objects

## Project Structure

The project is organized as a C# solution containing the main bookstore application.

```text
Bookstore/
├── Bookstore/
│   └── Application source code
└── ...
```

## Purpose

This project was developed as part of university laboratory exercises.

Its main purpose was to practice:

* C# programming
* object-oriented programming
* designing classes and relationships between objects
* implementing business logic
* working with a .NET project and solution

The application should therefore be considered an **educational project rather than a production-ready bookstore system**.

## Disclaimer

This project is a university programming exercise and is not intended to represent a complete commercial bookstore or e-commerce solution.
